# Review 01 - 2026-10-23 (Opus subagent, against v0.1)
Full findings table with fix status: see ../REVIEW.md. Summary of verdict: design sound; not safe for daily use until B1-B4 (child-crash hang, CSRF/DNS rebinding,
spawn-failure blocking, body cap) were fixed - done in v0.2. Real marginal RAM is PSS (router ~32 MB, child ~99 MB). Context saving mostly benefits clients that
load every tool schema (OpenCode). Pattern "reasonably novel" but niche; a natively multi-account upstream (taylorwilsdon/google_workspace_mcp) or Google's
official remote servers make the router unnecessary for Google specifically; publishing requires generalizing the hard-coded upstream.
Closest prior art named: MCPlexer. Not-quite-fit: mcp-proxy, supergateway, MetaMCP, mcp-router, Docker MCP gateway, lazy-mcp.
